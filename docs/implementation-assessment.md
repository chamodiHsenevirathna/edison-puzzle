## 3. Key decisions
* **Persistence:** SQLite (stdlib) on the server for puzzles (built-in + custom), saved solutions and validated attempts; browser `localStorage` for preferences, in-progress games and challenge progress. No accounts: an anonymous random client id (generated in the browser) tags attempts.
* **Streaming:** Server-Sent Events from a lazily evaluated solver generator; closing the connection stops the search. Hard server limits on nodes, time and events.
* **Single deployable:** the backend serves the built frontend; one process.
* **Upstream code:** not redistributed. The engine is an independent implementation of the same published algorithm idea; attribution is in `docs/licensing.md`.

## 4. Milestone log

### M2 Backend: done
* Engine: `symmetry.py` (families under board symmetries), `challenges.py` (7 challenges, pure evaluation), `analysis.py` (explains invalid/unsolvable puzzles), 3 warm-up puzzles, compact event encoding + replay helper, `Solver.cancel()/metrics()`, packaged exhaustive solutions of the original (generated by `scripts/generate_original_solutions.py`).
* API (`src/edison_api`): puzzles CRUD, analysis, bounded solve, SSE stream with cancellation on disconnect, validation, solutions + families, challenges, attempts, progress, SPA hosting. SQLite persistence.
* Verification: 317 fast tests, `ruff check` and `mypy` clean.
* Findings fixed on the way: default event cap (20k) truncated the original's 23,291-event trace -> 50k; stream disconnect leak covered by test.

### M3–M11 Frontend (foundation, Playground, Explorer, Compare, Gallery, Challenges, Creator, Results)
All built; one file per route. Defects found by tests and fixed during development: tray glyph labels overflowing (CSS font shorthand overrode SVG font size); axe label-in-name violations (tray/gallery buttons); accessible names without spaces; duplicate screen-reader announcement of errors; keyboard shortcuts dying when focus fell to `<body>` after a button became disabled; a request loop on the Results page (unstable object in an effect dependency); solver-event cap too small for the original's trace; mobile nav hidden behind horizontal scroll.
